## 7. Dashboard Architecture & Core Capabilities Reference

| Dashboard | URL | Authorized Roles | Core Platform Responsibilities |
| :--- | :--- | :--- | :--- |
| **Customer Portal** | `/portal` & `/quotes` | Customer, Shipper | Create instant quotations, compare multi-leg carrier alternatives, view dual-status approvals, and confirm/decline bookings. |
| **Platform Admin** | `/admin` | System Admin | Verify & approve freight companies (`is_eligible` toggle), manage user permissions, monitor system-wide shipments, inspect master database collections. |
| **Carrier Agent Workspace**| `/agent` | Carrier Agent, Broker | Carrier-isolated queue review, rate verification, pricing revisions (BAF/THC surcharges), quote approval or rejection. |
| **Customs Portal** | `/customs` | Customs Officer | Inspect Bill of Lading (B/L), commodity HS codes, verify container declarations, grant official customs clearance. |
| **Company Manager Hub** | `/analytics` | Company Manager | Assigned quote tracking, SLA compliance telemetry, ML regressor accuracy, and operational agent onboarding (email & password). |
| **AI Operations Hub** | `/agents` | AI Agent Operator | Autonomous AI agent health monitoring, route optimization telemetry, predictive pricing error logs. |
| **Public Live Tracking** | `/tracking` | Public / All Users | Real-time 8-stage container milestone tracking with geolocation coordinates and vessel ETA. |
