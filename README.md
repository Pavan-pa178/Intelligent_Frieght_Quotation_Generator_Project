# PORTLINE — Intelligent Freight Quotation & Operations Platform

An enterprise AI-driven multimodal freight quotation, statutory customs compliance, and carrier route optimization platform developed for global trade lanes (Ocean, Air, and Ground/Rail).

## Core Capabilities
- **5-Layer Dynamic Freight Pricing Engine**: Real-time spot tariff inference, liner surcharges, terminal handling charges (THC), and bunker adjustment factor (BAF).
- **Multi-Carrier Route Allocation**: Maersk, MSC, CMA CGM, Hapag-Lloyd, ONE, Blue Dart Aviation, VRL, and CONCOR dedicated partner desks.
- **12-Stage Quotation Lifecycle**: End-to-end sequential commercial review, tariff negotiations, statutory trade compliance validation, and shipper booking confirmations.
- **Statutory Customs Compliance Engine**: Automated HS code validation, EU UCC Art 127 advance filing checks, and dedicated document verification.
- **Multi-Agent Orchestration**: Autonomous AI agents for Pricing, Routing, Customs clearance, Risk assessment, and Operations tracking.

## Technology Stack
- **Frontend**: React 18, Vite 5, Tailwind CSS
- **Backend**: Django REST Framework, Python 3.10+, MongoDB Atlas
